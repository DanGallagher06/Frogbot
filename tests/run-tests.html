Frogbot number detection tests

Runs content/score.js against two sets of cases. Reload the page after editing the code or cases.

Development set

tests/detect-cases.js: the cases the code was built and fixed against.

Scoring

tests/score-cases.js: which sentences and table rows should outscore others, pass or miss the threshold, and get picked.

Facts

tests/facts-cases.js: the fact records (label, value, role, period, confidence) built from chosen sentences and table rows.

Held-out set

tests/holdout-cases.js: written from pages not used in development, never tuned against. This is the honest accuracy number.
